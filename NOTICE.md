# Notice

## Origin and independence

HUD Console Framework is an independent, from-scratch implementation created by
LosEcher. Its visual language was inspired by the aesthetic of a publicly
available sci-fi HUD web page; this project is not affiliated with, endorsed by,
or derived from that site's source code. All code in this repository is original.

## Fonts

`assets/fonts/` contains IBM Plex Mono, licensed under the SIL Open Font

MIT license of this repository.

## Demo data

All numbers, races, logs and telemetry shown in the demo are synthesized
programmatically at runtime by `js/core/synth.js` and the theme configurations
under `themes/`. Place and event names that appear (e.g. the Diagonale des Fous
race on La Réunion) are factual geographic/event references used for
demonstration only.
